## 1. Governance & Taxonomy Standards

This **Production Event Tracking Plan** formalizes the event telemetry catalog for VELOOP Rewards. In strict compliance with Section 12 of the task specification:
1. **Standardized Naming Convention:** All events strictly adhere to the `domain_object_action` hierarchy (e.g., `auth_user_registered`, `task_offer_started`, `payout_withdrawal_requested`). This eliminates ambiguous event naming across web, Android, iOS, and backend systems.
2. **Mandatory 16-Field Metadata Coverage:** Every single event defines its trigger, exact JSON payload requirements, validation rules, deduplication protocols, and downstream KPI dependencies.
3. **Comprehensive Coverage:** A total of **38 production events** are catalogued below (far exceeding the 25-event minimum mandate).
